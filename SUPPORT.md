# Getting help

Support is best effort. The maintainers and the community answer when they can. There is no promised response time.

## Where to ask

- **A question:** [Q&A](https://github.com/exceev-consulting/agent-crew-harness/discussions/categories/q-a) in Discussions.
- **Your setup:** [Show and tell](https://github.com/exceev-consulting/agent-crew-harness/discussions/categories/show-and-tell).
- **An idea:** [Ideas](https://github.com/exceev-consulting/agent-crew-harness/discussions/categories/ideas) in Discussions,
  or the [feature form](https://github.com/exceev-consulting/agent-crew-harness/issues/new?template=feature_request.yml).
- **A bug:** the [bug form](https://github.com/exceev-consulting/agent-crew-harness/issues/new?template=bug_report.yml).
- **A security problem:** a [private advisory](https://github.com/exceev-consulting/agent-crew-harness/security/advisories/new).
  See [SECURITY.md](SECURITY.md). Never a public issue or discussion.

## What to include

- **Harness version:** the `VERSION` file, or the commit you installed from.
- **Routine versions:** `bin/harness-render --status`.
- **Health check:** the output of `bin/harness-doctor`.
- **OS and Claude Code version.**
- The routine's run summary, if a routine misbehaved.

Read what you paste before you post: a run summary can name a private repository, a person, a host or a path. Remove
those. Never post `harness.json` with real values, an app private key, a token or a Telegram chat id.
